# RC Engine Log — Python/Kivy V1

App Android per registrare i litri utilizzati dai propri motori RC.

## Funzioni V1
- più motori
- totale litri automatico per motore
- totale generale
- sessioni con data, pista, litri e note
- modifica sessione
- database SQLite locale
- funzionamento offline

## APK
Su Linux/WSL con Buildozer:
1. `pip install buildozer`
2. `buildozer android debug`
3. APK in `bin/`

Su Windows è consigliato usare WSL2 Ubuntu per Buildozer.
